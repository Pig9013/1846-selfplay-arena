# v1.0.0 摘要（2026-10-28）

> 首个公开版本。完整工程变更见 [CHANGELOG.md](../../CHANGELOG.md)。当前版本见 [v1.3.0](v1.3.0.md)。

## 这一版是什么

一个本地运行的 1846 自战平台：用 18xx.games 开源规则引擎执行规则，机器人只生成候选，引擎最终裁判；网页可观战/回放；带一个 KataGo 式的最小自战训练回路；并用真实对局日志反查规则数值。

## 主要内容

- 规则感知候选生成（连接、瓦片库存、颜色/保留轨道、股份/列车限制、线路搜索）。
- 版图与规则数值导出（铺轨成本、边费、外域收入、Z/芝加哥瓦、车站、库存、奖励归属）。
- 网页观战/回放/训练面板。
- 自战训练回路（采样 → 推理 → 训练 → 热加载 → 对启发式评估）。
- 真实日志审计：95 份日志、69,494 条线路收入、99.99% 一致。
- 独立复核器：逐行动重放、收入重算、现金守恒。
- 示例对局与训练样本。

## 已知边界

- 标准 1846、3–5 人、无可选规则。
- 机器人候选未覆盖全部私营特殊能力/列车交易。
- 网页版图是数据驱动的简化绘图，不是官方美术。
- 真实日志无法逐行动重放（归档 API 返回空 actions，本地日志缺私营分配）。
