# v1.1.0 摘要（2026-10-28）

> 归档摘要。完整工程变更见 [CHANGELOG.md](../../CHANGELOG.md)。当前版本见 [v1.3.0](v1.3.0.md)。

## 这一版解决什么

v1.0.0 能跑完整局，但自战会退化：旧神经网络塌缩成“永远 pass”，255 局里几乎全是只 pass、不开办、不铺轨的样本。v1.1.0 先把回路修好，再谈策略。

## 主要变化

- **持续自战**：6 worker 默认一直跑；全局唯一局号；每局写 `train/games.jsonl`；每 1000 局自动分析；网页可启停。
- **神经网络修复**：动作候选携带 `type`，14 位动作类型 one-hot 生效；动作向量 48 维；网络残差按决策标准化（±3、权重 15）；采样温度 1.5、5% 均匀探索；pass-loop 守卫；旧 40 维/退化样本过滤。
- **旋转连通**：新增 `p1846/connectivity.rb`；铺轨按旋转后的真实路径算外域；接通 +42 + 0.6×收入，朝外不接 −30；C&WI 免费站可用；升级 token 映射修复。
- **芝加哥**：v1.1 曾用 D6/C5/芝加哥站硬编码把芝加哥拉高（这些在 v1.2.0 已删除）。
- **本地模型**：`GET /api/models` 报告检查点、nnserver 和外部模型；网页新增 `neural` 席位；说明“不是 LM Studio 驱动”。
- **分析**：`train/analyze.py` 生成 `logic-N.md`，含行动结构、前 1 采纳率、芝加哥/外域、胜负相关性、下一批修正。

## 验证

81 局报告：48,853 决策、0 退化；绿芝加哥 98.8%、至少一次 C5 95.1%、E/W 46.9%；接通外域 1,113 次、朝外不接 0 次；前 1 采纳率 54.0%、平均排序 1.74；破产率 7.4%。
