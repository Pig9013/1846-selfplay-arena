## 三个地方分别看什么

- **本目录**：面向使用者的版本更新、版本对比、已知差距。
- **[CHANGELOG.md](../../CHANGELOG.md)**：面向开发的逐条工程变更（Added / Changed / Fixed / Validation）。
- **[docs/status/](../status/)**：带日期的运行状态快照（多少局、什么网络、哪些指标）。

## 发布约定

- 版本号遵循 SemVer：行为/数据格式变化升 minor，修复和文档升 patch。
- 每次发布都写清楚“相对哪个版本”“改了什么”“哪些没解决”，不把版本说明塞回 README。
- 自战数据和分析报告示例放在 `examples/`：见 [examples/reports](../../examples/reports/) 与 [examples/selfplay](../../examples/selfplay/)。
