## 二、AI 是怎么想的

当前每个决策点的流程是：**引擎合法候选 → 启发式先验 → 神经网络残差 → 带温度的 softmax 采样**。没有 MCTS；引擎局面无法廉价克隆，所以用候选排序 + 先验蒸馏 + 结果加权来代替树搜索。

启发式先验里权重最高的是：

| 项 | 权重/规则 |
|:--|:--|
| 外域连接 | 旋转真正接通外域：+42，再按外域收入加 0.6×收入；只朝向外域却没接通：−30 |
| E/W | 已有 E 或 W 时接通另一半 +55；第一次接通任一侧 +14；向缺失侧靠近每个距离 +2 |
| 城市收益 | 新瓦城市收入 ×0.7；升级带来的收入增量再 ×0.45 |
| 通过性 | 同一路径连通边数 ×8 |
| 成本 | 铺轨成本 ×0.42 扣分；没钱买车时再扣 40 |
| 车站 | 保留/远程站 +22（不再有芝加哥专用加分） |
| 私营 | MS 44 / BIG4 34 / C&WI 30；再叠加人类频率先验 |
| 人类先验 | 各时代铺轨格/瓦、par、私营、买车/分红频率，默认权重 10，可设 0 关闭 |

实际决策统计：前 1 候选被采纳 **54.8%**，平均排序 **1.64**，先验熵 **1.19**，首选与次选平均分差 **19.9**。采样保留了明显的探索：不少局面没有直接选先验第一。

神经网络检查点：第 **228** 步，策略/价值损失 **1.4921**，对三个启发式席位的胜率 **50%**（4 人局随机基线 25%）。

网络只输出一个残差分数，经过**每个决策内标准化**（减均值、除标准差、截断 ±3）后按 15 分权重叠加。早期版本直接把原始 logit 乘 60，导致一个永远 pass 的局部最优压过全部启发式，整局退化；这一版已改为有界残差，并在采样时加入 5% 均匀探索。
